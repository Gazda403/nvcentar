## 🏛️ Impeccable White Architectural Design System

Ova verzija je redizajnirana po principima **Soft Structuralism** i švajcarske arhitektonske preciznosti:
- **Čista bijela podloga (`#FFFFFF`)** sa suptilnim arhitektonskim linijama i drafting mrežom (`rgba(15, 23, 42, 0.045)`).
- **Double-Bezel (Doppelrand) hardverska arhitektura:** Ugniježđeni kontejneri (spoljni `bg-slate-100 p-2 rounded-3xl border border-slate-200` i unutrašnji `bg-white rounded-2xl shadow-sm`) koji daju osjećaj precizno mašinski obrađenog hardvera.
- **Plutajuća ostrvska navigacija (Floating Island Capsule):** Odvojena staklena kapsula sa `backdrop-blur-xl`, zaobljenim ivicama (`rounded-full`) i *button-in-button* ugniježđenim ikonicama.
- **Tipografija visokog kontrasta:** Tamno mastilo (`#090D16`), grafit (`#334155`) i brend crvena preuzeta sa logotipa (`#B00615`).
- **Google Mape integracija:** Interaktivna Google mapa prilagođena direktno za NV Centar Banja Luka bez potrebe za eksternim API ključevima.
